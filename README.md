# Mio² – Downloads

Fertige Versionen von **Mio²** (Android): Reise-Spots aus TikToks und Instagram-Reels sammeln.
Der Programmcode liegt nicht hier – dieses Repo enthält nur die Updates.

**Installieren:** am einfachsten über Liams Appstore. Alternativ unter
[Releases](../../releases/latest) die Datei `Mio2.apk` laden und öffnen (Android fragt einmal
nach „Aus dieser Quelle installieren“).

**Updates:** Neue Versionen erscheinen hier unter Releases. Zu jeder Version gibt es eine
Prüfsumme (`SHA256SUMS.txt`) und eine kleine `android-update.json` mit Version, Größe und
Prüfsumme, die die App beim Update-Check liest.

Für Entwickler: Wie hier ein Release entsteht und wie die App in den Appstore kommt, steht in
[ANLEITUNG.md](ANLEITUNG.md).
